# 通用基线用例（参考示例）

> 这些用例是**参考示例**，展示 OWASP API Top 10 各维度的一种写法。**不是强制模板**——Agent 按目标系统自行设计用例，可改写、可删除、可自建，只需守住 SKILL.md §1.2 的 6 个机制（尤其「用例自带判定标准 + history」）。

维度一览：

| 目录 | 维度 |
|------|------|
| auth/ | 认证与会话 |
| idor/ | 水平越权（BOLA） |
| bfl/ | 垂直越权（BFL） |
| ura/ | 未授权访问与敏感数据 |
| conf/ | 安全配置（安全头 / CORS / 调试端点） |
| recon/ | 信息收集（指纹 / 报错泄露） |
| inject/ | 注入 |

ssrf / up_xss / biz / rl / 3rd 等其余维度按需自建。
