# 设计文档存放目录

将**所有项目相关的技术文档**放入此目录，越多越好。AI Agent 会自动读取并交叉参考。

## 可以放什么

| 类型 | 格式 | 对测试的帮助 |
|------|------|-------------|
| 接口文档 | `.md` `.docx` `.pdf` | 接口路径、方法、参数、鉴权要求 |
| 架构设计 | `.md` `.pdf` `.pptx` | 系统拓扑、网关/中间件、服务间调用关系 |
| 数据库设计 | `.md` `.pdf` | 表结构、敏感字段、用户/权限模型 |
| 需求文档 | `.docx` `.pdf` | 业务逻辑、支付/退款流程、角色权限矩阵 |
| 运维文档 | `.md` `.pdf` | 网络拓扑、安全配置、第三方依赖清单 |
| 前端代码 | `.js` `.ts` | Discover API paths, hardcoded keys, cryptography logic |
| 已有安全审计 | `.md` `.pdf` | 历史漏洞、已修复项、已知风险 |

## 支持的格式

| 格式 | 处理 |
|------|------|
| `.md` | 直接读取 |
| `.pdf` | PDF 读取（>50 页建议限制范围） |
| `.docx` | Word 读取 |
| `.pptx` | PPT 读取 |
| `.wps` | 需先另存为 .docx |

## 放多份文档的效果

Agent 会交叉参考：
- 接口文档告诉它有哪些端点
- 架构文档告诉它网关/中间件在哪里
- 数据库文档告诉它哪些字段敏感
- 需求文档告诉它业务逻辑有哪些环节

**文档越完整，测试覆盖越深，遗漏越少。**

## 如果没有文档

此目录留空即可，测试会自动切换为黑盒模式。
