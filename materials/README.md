# 设计文档存放目录

将以下类型的文件放入此目录，测试将自动读取：

| 文件类型 | 说明 | 示例 |
|----------|------|------|
| `.md` | Markdown 文档 | 接口文档、架构说明 |
| `.pdf` | PDF 文档 | 系统设计说明书 |
| `.docx` | Word 文档 | 接口规范、需求文档 |
| `.pptx` | PowerPoint | 架构图、流程图 |
| `.wps` | WPS 文档 | 请先另存为 .docx |

**优先级**：越完整的接口文档越有利于测试。理想情况下提供：
1. 接口地址 + 方法 + 参数定义
2. 认证/鉴权机制说明
3. 角色权限体系
4. 第三方服务依赖

**如果没有文档**：此目录留空即可。测试将以黑盒模式运行。
