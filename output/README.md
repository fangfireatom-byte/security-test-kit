# 测试产出目录

当前最新报告直接放在此目录下。历史报告自动归档到 `archive/`。

## 默认行为

Agent 默认操作 `output/` 中的**当前最新报告**，对其进行增量更新。

## 新一轮测试

当明确说"新一轮测试""重新测"时，Agent 会自动：
1. 将当前报告移动到 `archive/`，文件名加日期前缀
2. 创建新的空白报告继续测试

## 目录结构示例

```
output/
├── <项目>-测试报告.md          # 当前最新
├── <项目>-一页摘要.md
└── archive/
    ├── 2026-08-06-<项目>-测试报告.md   # 第一轮归档
    ├── 2026-08-06-<项目>-一页摘要.md
    ├── 2026-08-09-<项目>-测试报告.md   # 第二轮归档
    └── ...
```
